# ピアノロールのスナップ

[English](piano-roll.md)

ピアノロールには専用のスナップメニューがあります。エディターのヘッダー、またはコマンドパレットの **Piano Roll Snap…** コマンドから開けます。コマンドにはキーボードショートカットも割り当てられます。設定は起動後も保持され、曲や Undo 履歴は変更しません。

**Smart** は横方向のズームに合わせてスナップ間隔を調整します。**Bar** と **Beat** は編集位置の拍子に従います。**Division** はプロジェクトの分割設定に従います。固定音価は全音符から64分音符までで、三連符も含みます。**Free** では1ティック単位で編集できます。固定グリッドはズームしても間隔を保ちます。線が密になると見やすさのために間引かれますが、編集グリッドとの位置関係は保たれます。

既定値の **Absolute** では、ノートを移動またはコピーすると開始位置が曲のグリッドにそろいます。サイズ変更ではつかんだ端がグリッドにそろいます。**Relative** では元の開始位置または終了位置のずれを保ち、選択した間隔の倍数で移動します。他の選択ノートにも同じ差分が適用され、タイミングと長さの差が保たれます。縦方向だけのドラッグでは、ノートの時間位置は変わりません。

どちらのモードでも、新しいノートは曲のグリッド上に配置されます。最初の長さは最後に編集したノートの長さ、または1グリッド間隔です。**Snap ends** の切り替えは、ノートの右端をサイズ変更または描画するときのスナップを制御します。

ドラッグ中に **Control-Shift** を押すと、一時的にティック単位へ切り替わります。macOS では、ドラッグを開始した後に **Control** を押すと、プロジェクトの分割設定がより細かい場合にその設定へ微調整されます。従来の自由編集ジェスチャーである macOS の **Command** または Windows の **Ctrl** も引き続き使えます。ノート作成に使う修飾キーを押しても、描画中のスナップは無効になりません。

## 時間の移動

通常のマウスで時間を移動するには、アレンジメント、ピアノロール、ドラムグリッドの下にある水平スクロールバーをドラッグします。アレンジメントとノートエディターは時間位置を共有します。グリッド上で **Shift + マウスホイール** を使うと水平方向にスクロールできます。水平の時間スクロールバー上では、通常のホイールでも時間を移動できます。これらの操作で表示は変わりますが、曲は編集されません。
