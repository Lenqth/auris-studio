# 自動承認の証拠

[English](agent-review-evidence.md)

AutoReviewは、依然として独立したツール不要モデルに、実際の保留中の操作を評価するように要求します。拒否ルール、ワンタイムアクセス権限、文書改訂チェック、キャンセルは引き続き有効です。不確実性、不完全な出力、サポートされていない証拠、タイムアウトにより、操作は人間の判断を待つ保留状態に置かれます。

レビューリクエストには、人間のリクエスト、操作の根拠、プロジェクトフォルダ、最近完了したネイティブコール、および現在のプロジェクトローカルスクリプトが含まれます。以前の出力は、コールが完了した証拠であり、スクリプトが何を行うかを示す証拠や、別の操作を実行する許可を示すものではありません。アシスタントメッセージは同意を与えることはできません。

長いコマンドはCodexのリクエストおよびアイテムの表現に繰り返し表示されることがあります。64 KiBを超えるペイロードの場合、ロスレス`shared_text_v1`エンコーディングは少なくとも256バイトの文字列を1回保存します。`{text:N}`は`texts[N]`を指し、`{object:fields}`は元のオブジェクトを包み込み、配列は再帰的にデコードされ、プリミティブ値は変更されません。ラッパーは実際のオブジェクトとエンコーディング参照を区別します。コマンド、ディフ、または人間のリクエストは一切切り詰められません。最終リクエストは256 KiBで制限され、サイズが大きすぎる操作は承認できません。

デスクトップは、空欄のない完了した結果を含む、最大8件の最近の成功したネイティブ通話を提供します。レビュー作業者はこれらの観察事項の最大48 KiBを保持し、省略された項目を報告します。プロジェクトおよびその下の2つのディレクトリレベルの通常のUTF-8 `.py`、`.ps1`、`.sh`、`.js`、`.mjs`、`.cjs`、`.bat`、`.cmd`ファイルを独立してスナップショット化します。隠しパス、外部解決済みパス、リンク、一般的な生成ディレクトリは除外されます。インベントリは256件および16件のスクリプトレコードに制限され、内容はファイルあたり64 KiB、合計128 KiBに制限されます。欠落している、無効な、またはサイズが大きすぎる内容は明示的に利用できず、暗黙的に承認されることはありません。

コレクションはUIスレッドから実行されます。スナップショットには実際のバイトのSHA-256と完全なコンテンツが含まれています。承認されたレビューの後、ワーカーは推奨を返す前に解決されたパスとバイトハッシュを再確認します。変更されたスクリプトはそれを無効にします。これは時点でのチェックであり、認証後に別のプロセスがファイルを変更するのを防ぐOSレベルの保証ではありません。未知の依存関係は依然として同意が必要になる場合があります。

回帰カバーリングエクササイズでは、長文スクリプトの繰り返し、無損失デコード、文字通り参照形状のオブジェクト、現在のソースと前の出力の比較、変更されたファイル、過大サイズの証拠、フィルタリングされたコール履歴、変更されていない権限の動作が繰り返されました。

```sh
cargo test -p auris-agent approval_review
cargo test -p auris-gpui --bins ui::agent_chat::controls::tests
```
