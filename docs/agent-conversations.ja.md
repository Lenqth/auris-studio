# エージェントの会話

[English](agent-conversations.md)

エージェントパネルは各プロジェクトごとに別々の会話を保持します。**新しい会話**は既存の履歴とドラフトを保持します。**会話**は、最新のメッセージ順に並べられたリストを開きます。検索は会話タイトルに一致します。最初のリクエストで初期タイトルが指定され、会話メニューでは名前変更、アーカイブ、復元、削除が選択できます。**アーカイブ済み**フィルターは、アーカイブされた会話を表示します。

会話を開くと、モデルワーカーを開始することなくローカルの歴史が表示されます。メッセージを送信すると、プロジェクトの現在の状態に反してその会話が継続されます。歴史を開くと古い設定が復元されず、会話を削除すると音楽が削除されたり、元に戻す履歴が変更されたりしません。

ターンの実行中に、プレビューとして別の会話が開きます。元の会話は引き続き出力を受け取り、承認リクエストの所有権を保持します。承認処理を行うには元の会話に戻り、または**現在の作業を停止してこの会話を再開**を使用して、他の作業に移行する前に元のワーカーを停止します。プロジェクトに対しては、ウィンドウ間で実行される場合を含む、一度に1つの会話のみが実行できます。アイドル状態の会話は実行ライセンスを解放し、別のウィンドウが継続できるようにします。

<a id="persistence"></a>
## 粘り強さ

保存済みプロジェクトでは、会話を `.auris/agent/conversations/` 以下に保存し、識別子として扱う会話IDごとに1つのディレクトリを保持します。

- `meta.json`：タイトル、作成/更新時間、プレビューおよびアーカイブ状態；
- `transcript.json`：読み取れるメッセージ、ツール結果、ドラフト、スクロール位置；
- `memory.json`：次のリクエストに対する実行時の制限付きコンテキスト。

トランスクリプトはコンテキスト圧縮とは別に保持されます。ストリーミング出力は同じメッセージの識別子を更新します。スナップショットはバックグラウンドスレッドに書き込まれ、通常の編集中は1秒あたり最大2回です。復元された未完了のターンは中断済みとして記録され、自動的には実行されません。メタデータ操作にはストアロックを使い、トランスクリプトのリビジョンでは別のウィンドウからの古い書き込みを拒否します。削除するとランタイムメモリを無効化し、小さな削除痕跡を残すため、遅れて到着した書き込みが会話を復元することはありません。

最初にプロジェクトを保存する前は、会話データをアプリケーションのプライベートなリカバリディレクトリに保存します。ワークスペースの識別情報はプロジェクトの自動保存リカバリに従います。Save Asでは、ワーカーを分離してから会話を新しいプロジェクトにコピーします。会話の変更によってスコアが変更済みとしてマークされることはありません。

古い`.auris-conversation.json`ファイルは一度会話としてインポートされます。完了したやり取りと要約は保持されます。インポート後、古いランタイム生成は無効化され、古いファイルは削除されます。
