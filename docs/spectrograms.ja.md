# スペクトログラム

[English](spectrograms.md)

トラックヘッダーまたはレーンの空白部分を右クリックし、**Audio Display → Spectrogram** を選びます。オーディオ、インストゥルメント、ドラム、歌声、バスの各トラックで使用できます。オーディオトラックでは **Waveform**、それ以外のトラックでは **Clips** を選ぶと通常の表示に戻ります。クリップのタイトルと編集ジェスチャーは引き続き利用できます。

トラックヘッダーの上またはトラックの下にある空白部分を右クリックし、**Project Spectrogram** を有効にすると、クリップレーンの上にミックス全体を表示します。×ボタンで概要を閉じます。表示はアレンジメントの横方向のズームとスクロールに追従します。

オーディオクリップには元ファイルの周波数成分が表示されます。それ以外のトラックには、ステム書き出しと同じソロルーティングを通った演奏音が表示されます。バス、センド、マスター処理も含まれます。歌声トラックは、利用できる場合はレンダリング済みのテイクを使い、なければプレビュー用の楽器を使います。プロジェクト概要は、ミュート、ソロ、エフェクト、オートメーションを含む現在のミックスに従います。エフェクトの余韻も含まれます。

解析はバックグラウンドワーカーで実行されます。ドキュメントを変更するとレンダリング済みの表示が更新され、古い結果の代わりに読み込みメッセージが表示されます。表示を開閉してもプロジェクトや再生は変更されません。別のプロジェクトを開くと表示設定はリセットされます。

縦軸は対数目盛りで、20 Hz から 20 kHz とナイキスト周波数の低い方までです。色は −90 dBFS から 0 dBFS を表します。チャンネルは別々に解析するため、逆位相のステレオ信号も表示されます。画像は解析ウィンドウをまとめ、時間方向の列数を最大2,048列にします。長いアレンジメントをズームしても解析の解像度は上がりません。
