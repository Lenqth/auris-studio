# 強化前後の作曲試聴プロトコル

`melody-listening-v1.json` は、同じ依頼を強化前後の標準指示で実行するための固定マニフェストである。ポップバンド、6/8フォーク、シンセポップの3ジャンルについて、器楽曲と歌ものを1件ずつ用意した。各条件2回の探索的試行を行うが、試行数は統計的な効果判定には足りない。

各曲は24小節で、イントロ2・Aメロ8・サビ8・間奏2・終わり4に固定する。各ジャンルの器楽ケースと歌ものケースは同じテンポ・拍子・調・構成を使うが、編成は依頼文に定めた役割に従う（歌ものにはVocal、器楽曲にはLeadを置く）。比較するbefore/afterの各ケース内では、テンポ・拍子・調・小節数・歌詞・編成・トラック名を固定する。歌ものの歌詞は条件間で固定し、エージェントには歌詞・旋律・歌唱トラックを最後まで完成させるよう依頼する。パネル試験では歌声合成を行わず、保存された同じ譜面を後処理で同じVOICEVOX音源、話者、サンプルレート、seed `0`に通す。

実行は同一のビルド済みバイナリ、同じ`legacy`プロンプトプロファイル、同じモデル・backendで行い、候補ツールと編曲ハーネスは無効にする。runnerの`context_tokens=65536`は記録値であり、Codex CLIの実効コンテキスト長を指定するものではない。推論 effort は両条件ともbackendの既定値を使う。before/afterではバイナリを差し替えず、同じバイナリのデフォルトプロンプト先頭を凍結したprefixで置換する。beforeは`3aa05ca7`の作曲指示と対応するスキル資料、afterは`1708a2f9`の作曲指示と対応する強化後資料を`skill_context`として渡す。各条件2反復だが、LLMの反復seedは固定できないため、同一seedによる再現実験とは扱わない。マニフェスト内の乱数seed `20261025`は作曲ツール側の条件であり、LLM出力のseedを意味しない。

比較ページでは、最初に条件名を伏せたフルミックスを通して聴く。その後、主旋律／歌声、伴奏／器楽ステムを聴き、次の四点をバー番号または時刻付きで記録する。

- 自然さ：フレーズの向き、着地、音価、歌詞のアクセント、息継ぎ、音の解放。
- 覚えやすさ：一度聴いた後にリズムや輪郭を思い出せるか。狭い音域や同音反復も曲の役割に応じて評価する。
- 息継ぎ／プロソディ：歌ものでは休符だけでなく、長音の解放、語境界、子音の詰まり、次の弱起を確認する。器楽曲では「息継ぎ」をフレーズ間の余白と楽器のリリースとして扱う。
- 編曲：主旋律が埋もれないか、ベース・和声・ドラム・間奏に役割があるか、反復とセクション変化が自然か。

音量差の影響を抑えるため、ペア・聴取範囲ごとに実現可能な共通ラウドネスへ合わせたコピーを用意する。処理は一定ゲインだけとし、リミッター等は追加しない。元のfloat WAV、ピーク保護後の24-bit WAV、ペア音量合わせ後のWAVと測定結果を残す。主旋律／歌声と伴奏はそれぞれマスター処理を通した別レンダーであり、加算可能なドライステムとは扱わない。音量合わせは好みのための補助であり、音色・自然さ・覚えやすさを自動判定するものではない。

「tie」と「cannot_judge」は分ける。音声合成が失敗した、歌詞の読みが判断できない、または主旋律が単独で成立する意図か不明な場合はcannot_judgeとし、無理に優劣をつけない。評価ページの質問は試聴者にだけ表示し、生成エージェントの依頼文には混ぜない。

実験完了後は、曲別・条件別の全試行、失敗数、測定値、試聴者の判断を別々に報告する。少数試行の勝敗を「強化で改善した」と一般化せず、どの曲のどの箇所で自然さ・覚えやすさ・息継ぎ・編曲に差が出たかを示す。
