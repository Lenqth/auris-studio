# 物理楽器

[English](physical-instruments.md)

サウンドライブラリで **Physical Piano、Guitar、Electric Guitar、Bass、Bell、Mallet、Violin、Clarinet、Hammered Dulcimer、Tin Whistle** を選べます。それぞれ固有の安定 ID（例 `auris.physical.guitar`）を持つ組み込みプラグインです。新しいメロディートラックは Physical Piano を使います。サンプルファイルもネットワーク設定も必要ありません。**[Physical Choir](physical-choir.ja.md)** は、独自の声道／アンサンブル制御を持つ通常の楽器として、無歌詞のポリフォニックな母音アンサンブルを追加します。

これらは小型化した簡略物理モデルで、共通の制御語彙を使います。特定録音楽器の再現ではなく、演奏しやすく調整可能な楽器を目指しています。

| 楽器 | モデル | 便利な調整 |
| --- | --- | --- |
| Piano | フェルトハンマー、駒で結合したユニゾン硬弦、ダンパー、響板のノック | 接触硬さ、打撃位置、スティフネス、リリース（ダンパー）、ペダル |
| Guitar | 有限幅の撥弦、allpass 調整弦、ブリッジ運動出力 | ピック硬さ、撥弦位置、減衰、ピックアップブレンド |
| Electric Guitar | スチール弦ピックアップ DI、アコースティックボディ放射なし | ピック／ピックアップ位置独立、ピックアップ共鳴、オクターブごとの減衰 |
| Bass | 低いボディ共鳴を持つ撥弦 | 指／ピック硬さ、撥弦位置、共鳴減衰 |
| Bell | 減衰する非調和シェルモード | ビーター硬さ、励振位置、減衰 |
| Mallet | マリンバと同じく調律した音板（倍音は基音の4倍と約10倍） | 柔／硬ビーター、減衰、短／長共鳴 |
| Violin | 静止／滑り弓摩擦を持つ進行波弦 | 弓速度、圧力、応答時間、接触位置、表現、レガート |
| Clarinet | 円筒ボア導波管に結合した非線形単簧 | 息圧、リード硬さ、息ノイズ、アタック／リリース |
| Hammered Dulcimer | 有限ハンマーパルス、硬弦コース、受動ブリッジ結合 | ハンマー硬さ、打撃位置、弦減衰、ダンピング、スティフネス、コースデチューン |
| Tin Whistle | 開放管共鳴器に結合した非線形フィップルジェット | 息圧、ジェット形状、息ノイズ、アタック／リリース |

フィット済みフィルターカスケードがピアノ、ギター、バイオリンの色付けを行い、ギターとバイオリンには6つの因果放射共鳴を加えます。並列ボディ共鳴はベース、ベル、マレットを色付けします。ピアノはレジスターにより1、2、3本の弦と最大96部分音を使います。駒はユニゾンの弦が共有する運動だけを吸収するため、グランドピアノと同じく、音はまず速く減衰し、その後アフターサウンドとして長く鳴り続けます。損失、ハンマー接触、音量は C1〜C8 で測定した音域曲線に従います。詳しくは[鍵盤全体の調整記録](grand-piano-register.ja.md)にあります。バイオリンは1本の弓奏弦をモデル化し、弓、ブリッジ、木製ボディ全体のシミュレーションではなく、有界摩擦近似を使います。ベルのモード比は設計されたシェルを表し、特定製品のベルではありません。これらの選択で楽器を小さくし、制御を予測可能にしています。

<a id="controls-and-performance"></a>
## 制御と演奏

**Contact Hardness** と **Excitation Position** は初期アタックを変えます。柔らかい接触は高次モードを抑え、接触を動かすと一般的 EQ ではなく異なるモードを抑えます。ベロシティは励振エネルギーとアタック硬さの両方を変えます。**Resonance Decay** は基音が60 dB失われる公称時間を設定し、高次モードは先に減衰します。**Damping** は損失を加えます。ギターの allpass tuning は補間と物理損失を分離します。減衰は基音でキャリブレーションし、ダンピングは `1 + 3 × damping` 倍で短くし、高次モード損失を増やします。ギターとバイオリンには、G3／A4を中心とした滑らかなレジスター依存の接触／損失曲線もあり、その中心で減衰制御が公称になります。ベースとバイオリンの線形補間も周波数依存の損失を加えます。[改良の記録](physical-model-refinement.ja.md)に放射プロファイルと調整限界があります。

**Body Resonance**、**Level**、**Release**、**Damping**、**Resonance Decay** は発音中の音符に作用します。ピアノとダルシマーの **String Stiffness** は基音を調律したまま高次部分音を広げます。**Bow Pressure** はバイオリン専用で摩擦接合部に作用します。打弦／撥弦楽器の Position は次のアタックで効き、バイオリンでは約15 msかけて弓接合部を動かします。Stiffness は次のピアノ／ダルシマーアタックで効きます。ギターの **Pickup blend** はブリッジ運動放射からアコースティックボディ経由、位置依存の磁気ピックアップ近似へ移り、ボディ色付けを段階的にバイパスします。

**Electric Guitar** は独立した DI 楽器で、ピックアップ位置はピック位置と独立し、ピックアップは運動速度を観測します。共鳴ローパスが電気的応答を近似します。位置は開放弦を基準にし、標準調律と最高演奏可能弦から推定フレットと実効位置を決めます。**Decay per Octave** は E4より上の各オクターブで公称 E4 減衰を乗算し、下では除算します。クリーン／クランチ／リードのサチュレーションと開／閉スピーカーキャビネットには **Guitar Amp** エフェクトを追加します。[エレキギターの調整記録](electric-guitar.ja.md)に参照測定があります。

バイオリンの **Bow speed** は **Bow Pressure** とは独立に運動を制御します。**Bow response** は2〜120 ms（デフォルト約57 ms）の応答時間で、発音中も作用します。出力表現はその半分の時定数で滑らかに変化します。**Legato** は最後の音符を優先し、重なる音符は同じ振動弦を再利用し、最新キーを離すと前に押さえていたキーへ戻ります。ポリフォニック演奏ではデフォルトでオフです。レガートモードを変えると保持音を解放します。ほかの楽器と同様、パラメーターエディターとオートメーションレーンは通常のプラグイン状態を保存します。

クラリネットの **Breath Pressure**、**Reed Stiffness**、**Breath Noise** は発音するリード／ボア接合部を制御します。CC11 は息駆動と出力表現を20 msで平滑化します。16ボイスを持ち、**Attack** と **Release** は共通 ADSR を使います。[クラリネット調整記録](clarinet-calibration.ja.md)に実録音比較と対応測定範囲があります。

Hammered Dulcimer は24ボイスで、各コース3弦に最大24部分音があります。**Course Detune** はセント単位です。硬さ、位置、スティフネス、デチューンは次の打撃で効き、弦減衰とブリッジダンピングも発音中のコースに作用します。Tin Whistle は16ボイスと20 msの CC11 平滑化を持ちます。両方ともライブピッチベンドを尊重し、共通のデクリックエンベロープを使います。[民族楽器測定](folk-physical-instruments.ja.md)に実録音参照と調整限界があります。

MIDI CC7 はチャンネル音量を制御します。CC11 は表現とバイオリン弓速度を制御し、バイオリンでは平滑化前に `value^1.18` の応答を使います。CC1 は弓圧をスケールします。CC64 はピアノのダンパーをすべて上げます。解放した弦はペダルを上げるまで鳴り続け、すでにダンパーが下り始めた音もペダルを踏めば鳴り続けます。ピアノの **Release** はダンパーで、80 dB 減衰させるまでの時間です（低音ほど長くなります）。F6 より上の鍵にはダンパーがないため、グランドピアノと同じく離鍵後も鳴り続けます。響板のノックはダンパーで止まりません。ノートオフは音符を減衰／解放し、all-notes-off はプール全体を解放し、all-sound-off は共通デクリックエンベロープを使います。ピッチベンドは発音中の弦／モードに作用するため、既存のスライドとピッチ演奏ステージでこれらの楽器を演奏できます。弦／モードプールは最大24ボイスを保持し、先に解放済み／静かなボイスを奪います。励振は決定論的で、レンダーはブロックサイズに依存しません。

<a id="composition"></a>
## 作曲

曲はネイティブ楽器を直接選べます。

```toml
performance = "pop-band"
form = ["verse"]

[[part]]
name = "guitar"
role = "chords"
instrument = "auris.physical.guitar"
```

作曲家は、編集可能な stroke、strum、mute、slide、pitch-performance ステージを選ぶとき、ネイティブの piano、dulcimer、guitar、bass、violin、clarinet、whistle ID を認識します。既存の GM ファミリーヒントもこれらに解決されます。piano/electric piano、guitar、bass、bells（グロッケンシュピールとオルゴールを含む）、調律された音板（ビブラフォン、マリンバ、シロフォン）、strings、clarinet（GM 71）、dulcimer（GM 15）、whistle（GM 78）です。ミュートギターヒントは強いダンピング、picked/slap bass は硬い接触、string pad は穏やかな弓圧と長いリリースで始まります。これは Auris 楽器の開始パラメーターで、GM パッチのエミュレーションではありません。ドラムヒントは組み込み Drum Kit を使います。

伴奏も同じ選択を使います。ネイティブトラックには SoundFont 参照が不要です。明示的な SoundFont ソースまたはインポートしたプリセットは、そのフォントを選び続けます。未対応ファミリーは、セッションの既存フォールバックまたは任意のインストール済み GM ライブラリを使います。メロディー役はレガート付きネイティブバイオリン、パッド役は遅い弓運動とポリフォニーで始めます。明示的なパラメーター選択が優先され、楽器選択で音符やシード付きレシピは変わりません。

<a id="mechanical-editor"></a>
## メカニカルエディター

トラックの楽器行から物理楽器のパラメーターエディターを開きます。**Model motion** 領域は通常のパラメーターの隣にあり、ピアノ／ギター／ベース／バイオリンは弦、マレットは棒の曲げ、ベルはシェル外周を表示します。再生またはミュージカルタイピング中は選択トラックとは独立に編集トラックへ追従します。**Play C4** はテスト音を保持し、**Release C4** は減衰させます。オクターブボタンは保持状態を保ったままテスト音を変えます。エディターを閉じるか置き換えるとテスト音を解放します。

直近4ボイスまで、音符／ベンド、保持／リリース状態、相対空間運動を表示します。マーカーは励振接触を示し、動く弓インジケーターは実際の弓運動に従い、モード楽器は最初の8共鳴振幅を表示します。ピアノ／打弦／撥弦の接触は次のアタックまでそのボイスの励振位置にあり、バイオリンは発音中に平滑化された接合部に従います。表示には表現、バイオリン弓圧、ピアノペダル状態も含まれます。

ギターとエレキギターは標準 E–A–D–G–B–E の6弦、ベースとバイオリンはそれぞれ E–A–D–G、G–D–A–E の4弦を使います。高い弦は低い弦の上に表示され、ギター／ベースのフレットはブリッジに向かって短くなります。ボディ、サウンドホール、ピックアップが接触／停止位置の基準を与えます。弦割り当ては音高から推定した模式的な運指で、モニターは物理的な弦 ID を報告しません。調律範囲外の音符は最低弦に表示されます。

ピアノは、白鍵／黒鍵の中心に揃えた垂直の弦投影を持つ88鍵 A0–C8 の永続キーボードです。低音弦は高音弦より長く、長さは模式的です。ピッチベンドは隣の鍵中心間を連続して動きます。発音中の鍵は強調され、弦の上に音符、セント、保持／リリース表示、キーボード下にサステインペダル表示があります。範囲外の音符は端に描き、表示値は発音ピッチを保ちます。

Drum Kit はキック、スネア、ハイハット、3つのタムレジスター、クラッシュ、ライドを固定位置に置きます。休止中の膜、シンバル、メッシュは無音やヒットの間も見え、新しいボイス順と数でキットを並べ替えません。クローズ／オープンハイハットは1パッドを共有します。捕捉した膜／プレート運動と接触マーカーを表面に重ね、Effects 有効時は最近一致した形に軌跡を加えます。モニターは直近4ボイスまでなので、完全な休止キットは配置の基準であり、全ヒットを捕捉したという主張ではありません。

色はアクティブテーマのトラックパレットに従います。短い軌跡は捕捉形状を保ち、運動の火花と励振ハローは空間データを変えずにエネルギーを強調します。**Effects** は軌跡、ハロー、火花を無効にし、エディターを変えても保持されます。**Freeze** は形状とエフェクトを保持します。

図はボディ色付けと出力ゲインの前に、ライブ波形履歴または低モード空間投影を使います。メートル単位の変位ではなく相対的な機械表示です。ディレイループは固定端の空間投影を、ベル／棒のモード基底はライブモード座標の説明用幾何投影を表示します。毎秒約30回の表示更新で、音声レートモデルのスローモーション積分ではありません。固定の6/24/96×表示倍率で運動と減衰を見やすくします。**Freeze** はスナップショットを保持して観測を止め、**Resume display** は再開します。両状態で音声は動き続けます。

パラメーター操作は通常のキーボード調整、入力値、リセット、オートメーション、保存／読み込み、1ジェスチャー Undo を保ちます。小さいサイズではウィンドウがスクロールし、Tab でテスト音／表示ボタンとスライダーに移動、Enter/Space でボタンを実行、Escape で閉じます。

<a id="development-verification"></a>
## 開発検証

```sh
cargo test -p auris-synth -p auris-compose -p auris-session
cargo run -p auris-synth --example physical_demo -- target/physical-demo.wav
cargo run --release -p auris-synth --example physical_bench -- --motion
cargo test -p auris-gpui --bins physical_model
```

テストは複数レートのピッチ、ベロシティ応答、硬さ依存の高次モード、減衰／サステイン、ペダルリリース、ピッチベンド、極端な設定、コールバック割り当てを測定します。共有テストはイベントオフセット、モノ／マルチチャンネルバッファ、決定論的レンダーも対象にします。例は試聴プローブを書き、各モデルのピークと RMS を報告します。メカニカル観測テストは監視あり／なしの PCM をビット単位で比較し、固定弦端点、有限でゼロでない運動、同時の一貫した読み取り、撥弦接触保持、廃止グラフリーダー無効化、観測時のコールバック割り当てを検査します。ネイティブウィンドウハーネステストは、プレビュー、キーボード表示倍率、freeze/resume、パラメーターへのスクロール、Undo、ソース置換、Escape を対象にします。

[放射／レジスター実験](physical-extensions.ja.md)は、因果共鳴、レジスター曲線、弓応答を実録音と保留時間メル損失で比較します。[長音／軌跡キャリブレーション](physical-trajectories.ja.md)は、持続音、演奏したビブラート／グリッサンド、表現追従、リリースを実録音と比較します。工場のピアノ、ギター、バイオリン設定と放射ゲインは[時間メルコピー合成](physical-copy-synthesis.ja.md)で実録音に対して調整します。その文書には目的、固定した訓練／検証分割、再現コマンド、残る制限があります。[ベース／バー／ドラム測定](physical-pack.ja.md)は残りの物理モデルと7つのキットファミリーを、アタック、ボディ、テール、エンベロープの個別誤差で調整します。[変更前後の測定](physical-instruments-evaluation.ja.md)は、持続弦と ambient アレンジの低い学習済みスコアを含む、全プリセット比較を記録します。

設計は Julius O. Smith の[Physical Audio Signal Processing](https://www.dsprelated.com/freebooks/pasp/)にあるモード展開と進行波の原理、特に[モード展開](https://www.dsprelated.com/freebooks/pasp/Modal_Expansion.html)と[弓奏弦](https://www.dsprelated.com/freebooks/pasp/Bowed_Strings.html)に従います。
