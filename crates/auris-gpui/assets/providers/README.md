# Provider marks

Monochrome SVGs from [Lobe Icons](https://github.com/lobehub/lobe-icons),
`@lobehub/icons-static-svg` version 1.98.0, distributed under the included MIT
license. Brand names and marks belong to their respective owners.

The application embeds these files and tints them with its theme foreground.
OpenAI represents Codex; an arbitrary OpenAI-compatible endpoint uses a neutral
API mark because API compatibility does not identify its operator.
